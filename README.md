# Ethan Diec CS280 Projects

Course portfolio plus assignment code.

```
ui/          React portfolio site (GitHub Pages)
project-1/   Images of the Russian Empire
```

## Site

From the repo root:

```bash
npm run dev
```

Or `cd ui && npm run dev`. The GitHub Pages workflow builds `ui/` and deploys `ui/dist`.

## Project 1

Python alignment pipeline lives in `project-1/project-basics` and `project-1/project-bells-whistles`. Create a venv there and `pip install -r project-1/requirements.txt` if you want to rerun it.
